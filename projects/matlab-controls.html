MATLAB Controller Comparison

Compared proportional and PD controllers using simulated step responses.

System model

I modeled the plant 1/[s(s + 1)] with unity feedback and compared proportional control with a proportional-derivative design.

Response comparison

I used step plots and stepinfo to compare settling time and overshoot. The PD design targeted a shorter settling time. The plot shows the simulated response of both designs to the same unit-step input.

View MATLAB code
% q3

s = tf('s');

% (a) original system @ 5% OS
zeta = 0.690; wn = 1/(2*zeta); K = wn^2;
G = K/(s*(s+1)); T1 = feedback(G,1); stepinfo(T1)

% (b) PD design to halve Ts
z = 2.12; Kc = 0.99;
C = Kc*(s+z);
T2 = feedback(C/(s*(s+1)),1);
stepinfo(T2)

figure; step(T1, T2); legend('K-only (Ts ~ 8s)','PD (Ts ~ 4s)'); grid on
